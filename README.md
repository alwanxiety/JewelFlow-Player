## Основные фичи

- **Уникальный интерфейс:** Интерактивная карусель визуального отображения треков в виде пластиковых боксов.
- **Высокий уровень оптимизации:** Несмотря на привлекательный внешний вид, потребление ресурсов остается минимальным.
- **Удобство:** Автопоиск текста для треков с режимом караоке и другие улучшения, создающие *user experience* привычных стриминговых платформ.
- **Интеграции:** Возможность использования каталога Яндекс Музыки для прослушивания.

---

## Используемые компоненты

- [miniaudio](https://github.com/mackron/miniaudio) — легковесная библиотека для работы со звуком в реальном времени.
