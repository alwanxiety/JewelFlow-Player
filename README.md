## ✨ Основные фичи

- **Уникальный 3D-интерфейс:** Интерактивная карусель визуального отображения треков в виде пластиковых боксов.
- **Высокий уровень оптимизации:** Несмотря на привлекательный внешний вид, потребление ресурсов остается минимальным.
- ~~**Удобство:** Автопоиск текста для треков с режимом караоке, создавающий *user experience* привычных стриминговых платформ.~~ (в планах)

## 📝 Используемые компоненты

- [miniaudio](https://github.com/mackron/miniaudio) — легковесная библиотека для работы со звуком в реальном времени.
